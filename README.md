# 台鐵旅客資訊服務系統

一套 Windows 旅客資訊看板與車站廣播應用程式，結合交通部 TDX 運輸資料，提供台鐵、高鐵及部分捷運模式的列車資訊顯示、廣播管理和車站設定。

> **使用前請注意：** 本程式的資訊可能受資料來源、網路、更新頻率、設定與授權狀態影響，畫面及自動播報不保證等同實際列車位置或現場狀況；請以各運輸業者及車站現場公告為準。不同版本與交通模式的功能可能不同，請參閱下載頁的版本說明。

## 下載與安裝

請至 [GitHub Releases 下載頁](https://github.com/Amor5599/Taiwan-Railways-Display-Panel/releases) 選擇版本：

| 檔案 | 用途 |
| --- | --- |
| `TR_sche-Setup.exe` | Windows 安裝版，依安裝精靈操作。 |
| `TR_sche-Portable.exe` | Portable 版安裝或更新工具，請依畫面選擇程式所在資料夾。 |
| `TR_sche-Portable.zip` | 免安裝版；解壓縮後執行資料夾內的 `TR_sche.exe`。 |

實際可下載檔案以各版本的 Assets 為準。標示 **Beta / Pre-release** 的版本為測試版，可能仍有問題；請先備份設定及重要資料。

### 第一次使用

1. 下載安裝版或 Portable 版並啟動程式。
2. 依初次設定畫面選擇車站及需要的設定；如畫面提供匯入既有設定，可依指示選擇。
3. 在偏好設定中確認 TDX API、顯示器、廣播內容、音檔與輸出裝置。
4. 儲存設定後檢查看板、列車資料與播音結果。切換運輸模式時依程式提示操作，必要時重新啟動以載入該模式設定。

網路連線、TDX 帳號與有效 API 憑證可能為取得部分資料所必需。未設定或連線失敗時，部分資訊與自動功能可能無法使用。

## 運輸模式

程式可在「偏好設定 → 車站 → 運輸模式」管理及切換交通模式。高鐵及捷運車站使用獨立設定；可選擇已建立車站，亦可依介面新增或刪除車站。切換前請先保存目前修改。

### 台鐵

- 以車站看板方式顯示列車資訊，包含車次、車種、方向、目的地、時間、月台及狀態等；實際欄位依看板而異。
- 可選用不同風格的顯示器，並調整適用的字級、列數、版面、跑馬燈與顯示範圍。
- 支援列車廣播管理、手動播報、自動排程，以及晚點、停運等車次相關設定。
- 可依車站資料及設定顯示或播報自由座、沿途停靠與其他資訊。

### 高鐵

- 使用獨立的車站及顯示設定，提供高鐵列車資訊看板。
- 支援高鐵即將進站及現在停靠等廣播；可依設定使用中文、英文、台語及客語音檔。
- 可設定月台及自由座車廂配置，並使用 JSON 匯入／匯出適用的自由座資料。
- 提供當日車次狀態的手動調整。可用資訊仍依資料來源與設定而異。

### 捷運

- 提供北捷、新北捷運及桃園機場捷運等模式及車站設定；可用線路與資料依版本及業者提供情形而異。
- 看板可呈現目的地、方向與到站倒數；部分版面提供廣告影片／圖片、宣導跑馬燈及車廂擁擠度區域。
- 支援設定顯示方向及廣告媒體資料夾；沒有廣告時可使用預設畫面。
- 部分捷運廣播可依車站、目的地、月台、方向及音檔設定自動或手動播放。車廂擁擠度若未提供，畫面會標示資料未提供，不代表車廂空位狀況。

捷運倒數可能由即時資料或時刻表估算，並非一定是列車的即時位置。不同業者、車站或資料介面可能無法提供相同欄位。

## 廣播功能

### 廣播管理介面

使用 **F2** 開啟廣播管理介面，可依畫面提供的功能：

- 查看、搜尋及篩選廣播計畫和列車資料。
- 新增單筆或批量廣播，管理自訂計畫及播放內容。
- 播放、停止、刪除或刷新項目；可使用右鍵選單處理適用的操作。
- 查看列車廣播文字預覽、播音狀態與廣播時間軸。
- 管理晚點／停運、車次配置及排程相關設定。

自動計畫、觸發時機及可用操作依交通模式、資料是否取得與廣播設定而定；文字預覽不代表廣播已實際播放。

### 廣播內容與音訊

- 可在偏好設定中調整廣播內容、語言、頻率、速度及提示音等。
- 可設定音檔資料夾及音訊輸出裝置；高鐵、捷運與台鐵有各自適用的設定。
- 支援安全／宣導、車站音樂、下雨提醒與其他適用的站務廣播設定。
- 可設定輸出分區；適用模式亦提供喇叭方向或播放範圍設定。
- 可調整音檔銜接與音訊效果；實際效果受音檔、播放裝置及所選設定影響。

音檔必須符合程式支援的格式、檔名及資料夾配置；缺少必要音檔、未啟用語言或未選擇合適的輸出裝置時，可能無法播報。首次使用建議先以小音量確認音訊與分區。

## 看板與跑馬燈

- 可依交通模式、車站與顯示器調整適用的畫面設定。
- 支援列車資訊、站務宣導、廣告及緊急公告等適用的跑馬燈內容。
- 可調整支援版面的跑馬燈顯示方式、速度與相關選項。
- 部分設定支援 JSON 匯入、匯出與編輯；匯入前請備份原有設定。
- 捷運廣告區可依設定輪播資料夾中的影片或圖片；支援格式及播放能力依執行環境而異。

## 設定與資料

使用 **F3** 開啟偏好設定。依目前模式與版本，設定頁面可包含車站、運輸模式、API、顯示器、播放及音訊、跑馬燈、月台、自由座、帳號與系統等項目。設定完成後，請使用對應的「保存」按鈕。

- **車站與模式：** 管理車站、切換交通模式及調整模式專屬選項。
- **顯示設定：** 選擇支援的看板，調整顯示內容與外觀。
- **播放設定：** 設定廣播內容、語言、輸出裝置、音檔與排程。
- **API：** 設定 TDX API 憑證；帳號同步功能的可用性依版本及服務狀態而定。
- **匯入／匯出與備份：** 可在適用頁面匯入或匯出設定、跑馬燈或其他支援的資料。操作前請檢查匯入範圍並先備份。
- **搜尋設定：** 可使用設定頁頂端搜尋欄尋找分頁或選項。

請勿公開分享 API 金鑰、帳號密碼、授權資訊或含有個人資料的設定檔。

## 更新程式

可在「偏好設定 → 車站 → 檢查更新」查看目前版本與可用更新。開啟「接收 Beta 版更新」後，檢查範圍會包含預先發布的測試版。

更新前請保存工作並備份重要資料。安裝版與 Portable 版請使用對應的更新方式；具體步驟及保留資料範圍以更新程式和各 Release 說明為準。

## 常見問題

**沒有列車資料或看板為空白？**  
確認交通模式、車站、日期時間、網路及 TDX API 設定，並檢查資料來源是否提供該車站資訊。時刻表、即時資料及畫面更新可能有延遲。

**有看板但沒有廣播？**  
確認已啟用適用的自動廣播及語言，檢查音檔資料夾、音檔命名、喇叭輸出、音量與方向／分區；再查看廣播管理介面的時間軸及略過原因。

**設定保存後沒有生效？**  
確認已按該頁或偏好設定的「保存」，並檢查目前編輯的車站、模式與顯示器。切換模式後如程式提示重新啟動，請依提示操作。

**不同版本的功能或畫面不一致？**  
請確認所使用的安裝版或 Portable 版本，以及 Release 是否為 Beta。更新說明中的修正只適用於包含該修正的版本。

## 資料來源與使用提醒

本程式可使用 [TDX 運輸資料流通服務](https://tdx.transportdata.tw/) 的資料；資料內容、權限、額度、更新頻率與服務可用性由資料提供者決定。網路異常、資料延遲或未提供欄位時，畫面及播報可能無法反映實際狀況。

本專案為獨立應用程式，並非各交通業者的官方即時資訊系統。使用者應自行確認所使用之音檔、圖片、影片及其他素材的授權。
